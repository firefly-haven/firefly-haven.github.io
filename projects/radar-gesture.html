60 GHz Radar Gesture Recognition

Adapting an Infineon PSoC 6 radar gesture-recognition example into an interface that could trigger and communicate with a larger embedded system.

View repository ↗

Problem

Turn gesture classification into a usable system signal.

The starting point was an Infineon DEEPCRAFT radar deployment example for a PSoC 6 AI Evaluation Kit. The example could classify gestures from the XENSIV 60 GHz radar sensor, but a larger embedded system still needed a clean way to react to those detections.

My contribution

Embedded integration

  • Modified the application behavior around detected gestures.
  • Added a GPIO output that can act as a hardware trigger for another device.
  • Added UART output for communicating detected events digitally.
  • Configured the required PSoC GPIO resources.
  • Integrated the radar gesture stage into a broader wearable-system concept.

Architecture

Signal flow

XENSIV 60 GHz Radar │ ▼ PSoC 6 AI Evaluation Kit │ ▼ Radar sampling / preprocessing │ ▼ DEEPCRAFT ML inference │ ▼ Gesture classification │ ├────────► GPIO trigger │ └────────► UART event output
